# دليل متغيرات البيئة (Environment Variables)

هنا شرح متغيرات البيئة وتأثيرها الفعلي. أضفها إلى `.env` محليًا أو إلى
إعدادات Variables في منصة الاستضافة، ولا تضع القيم السرية داخل الكود.

| المتغير | إلزامي؟ | الوصف | التأثير لو غلط/ناقص |
|---|---|---|---|
| `DATABASE_URL` | ✅ | connection string لـ PostgreSQL (Supabase) | السيرفر يفشل في الإقلاع فورًا |
| `DATABASE_SSL` | لا (افتراضي true) | تفعيل SSL للاتصال بقاعدة البيانات | معظم مزودي Postgres السحابيين يرفضوا الاتصال بدونه |
| `DATABASE_POOL_SIZE` | لا (افتراضي 10) | أقصى عدد اتصالات متزامنة بقاعدة البيانات | قيمة صغيرة جدًا = بطء تحت الحمل، كبيرة جدًا = استهلاك موارد قاعدة البيانات بلا داعي |
| `JWT_SECRET` | ✅ (32+ حرف) | مفتاح توقيع جلسات الدخول (JWT) | السيرفر **يرفض الإقلاع** لو غير موجود أو قصير — إجراء أمان مقصود منذ Stage 5 |
| `ALLOWED_ORIGINS` | لا | قائمة origins مفصولة بفاصلة، تقيّد CORS | لو فاضي، الـ API مفتوح لأي origin (مقبول لو الفرونت اند بيتقدّم من نفس السيرفر) |
| `PORT` | لا (افتراضي 5000) | البورت اللي السيرفر بيستمع عليه | — |
| `OWNER_EMAIL` | لا (افتراضي `oalaaofficial@gmail.com`) | البريد الذي يستقبل رموز دخول حساب المالك | — |
| `RESEND_API_KEY` | موصى به على Railway Free/Trial/Hobby | مفتاح Resend لإرسال رمز المالك عبر HTTPS؛ عند ضبطه يستخدمه النظام بدل SMTP | تعذر إرسال الرمز إذا كان المفتاح غير صالح أو لم يُضبط عنوان إرسال موثّق |
| `RESEND_FROM_EMAIL` | مطلوب مع `RESEND_API_KEY` | عنوان From تابع لنطاق تم توثيقه في حساب Resend | رفض Resend الطلب إذا لم يتطابق العنوان مع نطاق موثّق |
| `GMAIL_USER` | لا (افتراضيًا يساوي `OWNER_EMAIL`) | حساب Gmail المرسل عبر SMTP، للاستخدام في بيئة تسمح باتصالات SMTP | تعذر إرسال رمز المالك إذا كان البريد غير صالح أو المنفذ محجوبًا |
| `GMAIL_APP_PASSWORD` | مطلوب عند استخدام Gmail SMTP | App Password لحساب Gmail المرسل، وليس كلمة مرور Gmail العادية | تعذر إرسال رمز المالك |
| `NODE_ENV` | موصى به `production` | يفعّل سلوك الإنتاج (تفاصيل أخطاء أقل تفصيلاً للمستخدم النهائي، إلخ) | — |
| `TELEGRAM_BOT_TOKEN` / `TELEGRAM_CHAT_ID` | لا | إشعارات تيليجرام (نقص مخزون، تذكير أقساط، فشل نسخ احتياطي) | لو فاضيين، الإشعارات تتجاهل بصمت، النظام يشتغل عادي |
| `BACKUP_DIR` / `BACKUP_RETENTION_DAYS` | لا | مسار وفترة احتفاظ النسخ الاحتياطي المحلي (`deploy/backup.sh`) | القيم الافتراضية (`./backups`, 14 يوم) كافية لمعظم الحالات |

## أمان الأسرار

- على Railway Free/Trial/Hobby استخدم Resend عبر HTTPS، لأن هذه الخطط تحجب SMTP الصادر. الخطة المجانية الحالية في Resend تشمل 3,000 رسالة شهريًا وبحد 100 رسالة يوميًا؛ يلزم نطاق موثّق وعنوان إرسال تابع له للإرسال الفعلي. راجع [توثيق Railway للشبكات الصادرة](https://docs.railway.com/networking/outbound-networking) و[أسعار Resend](https://resend.com/pricing).
- لإنشاء `GMAIL_APP_PASSWORD`، فعّل التحقق بخطوتين في حساب Gmail ثم أنشئ App Password مخصصًا للتطبيق. استخدمه فقط في استضافة تسمح باتصالات SMTP، ولا تحفظه في الكود أو Git.
- لا تشارك ملف `.env` أبدًا (Git، رسائل، أو ملفات مشتركة). شارك أسماء
  المتغيرات المطلوبة فقط، واحفظ القيم في إعدادات البيئة السرية للاستضافة.
- لو أي سر (خصوصاً `DATABASE_URL` أو `JWT_SECRET`) اتكشف بالغلط ولو مرة
  واحدة، اعتبره **مخترق دائمًا** وابدّله فورًا من مصدره — تغييره مرة
  واحدة تاني مش كافي لو النسخة القديمة اتشاركت في أكتر من مكان.
